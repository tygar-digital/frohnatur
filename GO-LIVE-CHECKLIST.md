# Go-Live Checklist — Frohnatur

Die Website ist technisch fertig. Vor der Veröffentlichung brauchen wir folgende Daten vom Kunden.

---

## Vom Kunden benötigt

### 1. Impressum-Daten (Pflicht)
- [ ] Vollständiger Name des Betreibers (Vor- + Nachname oder Firmenname)
- [ ] Telefonnummer
- [ ] E-Mail-Adresse
- [ ] USt-IdNr. (falls vorhanden)

### 2. Telefonnummer
- [ ] Echte Telefonnummer für die Website (Kontakt-Sektion + Impressum)

### 3. Fotos vom Laden (4 Stück, Hochformat)
- [ ] Innenraum-Gesamtansicht
- [ ] Sitzbereich
- [ ] Latte Art / Kaffee-Detail
- [ ] Gebäck / Kuchen-Detail

> Format: Hochformat (3:4), min. 1200x1600px. Handy-Fotos reichen.
> Alternativ: Wir generieren KI-Bilder — Prompts liegen bereit (BILD-PROMPTS.md).

### 4. Domain
- [ ] Welche Domain? (frohnatur.de, cafefrohnatur.de, ...)

---

## Von uns zu erledigen (bei Go-Live)

- [ ] Kundendaten in Impressum + Datenschutz eintragen
- [ ] Telefonnummer in Kontakt-Sektion + Schema.org eintragen
- [ ] Galerie-Platzhalter durch echte Fotos ersetzen
- [ ] OG-Image erstellen (1200x630px)
- [ ] Draft-Banner entfernen
- [ ] Vercel Deployment einrichten
- [ ] Domain + DNS konfigurieren (Cloudflare)
- [ ] SSL prüfen
- [ ] Finaler Lighthouse-Check
