# Lessons Learned

## Hero-Elemente nie wiederverwenden
**Datum:** 2026-03-25
**Kontext:** Charakter2.svg in Kontakt-Kartenbereich eingebaut, obwohl es schon in Story verwendet wird.
**Regel:** Jedes visuelle Hero-Element (Charaktere, Lampe, Illustrationen) darf nur EINMAL auf der gesamten Seite erscheinen. Wenn eine Sektion ein visuelles Element braucht, muss es ein neues oder ein rein typografisches/dekoratives Element sein — nie ein bereits verwendetes Asset recyclen.
